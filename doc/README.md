Course materials
================

This folder holds the teaching materials for the two-day block **Data architecture, FAIR, ontologies
and retrieval**, week 2 of the curricular unit *Analysis of Biological Data from the Gene to the
Ecosystem* (DABDGE) at the University of Minho. For the framing of the block within the CU as a
whole, its preparations, assessment and hand-offs, see [the repository README](../README.md).

The anchor question for the two days is:

> **How is a biological record structured, made interoperable, and used?**

Day 1 answers the first part in lectures: what a record is made of, how it is identified, how it is
serialised, and what it can be joined to. Day 2 answers the rest at the keyboard: you retrieve
records, audit what is missing from them, annotate a table of your own, link one sample across
several resources, and package the result so that it would survive the audit you performed in the
morning.

How to read this
----------------

The material is written to be read in order, and each day assumes the one before it. The lectures
carry a worked example through both sessions, and the practicals pick up the same records and the
same vocabulary. If you have to miss a session, read the lecture notes before the practical rather
than after it: the practicals are written on the assumption that the terms have already been
defined.

Everything here is plain Markdown, so it can be read on GitHub, on the rendered pages, or in a text
editor offline. Figures live in a folder next to the file that uses them. Corrections and issues are
welcome, including from students.
